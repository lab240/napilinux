## Обновление NapiLinux 0.2.8.1

>**[Скачать...](https://download.napilinux.ru/napilinux/)**

Вышел релиз napi-linux 0.2.8.1
Скачать: https://download.napilinux.ru/napilinux/0.2.8.1

## Что изменилось

* Добавлен recovery раздел — устройство теперь более корректно работает при обновлении системы
* Переработан процесс обновлений (SWUpdate) — теперь он более надёжный
* Добавлены пакеты:
    * discoverd
    * napi-motd
    * tcpdump
    * tree
    * xxd
    * git
    * can-utils
* Обновлён веб-интерфейс и API:
  * улучшено управление модулями системы
  * добавлена логика, учитывающая тип дистрибутива устройства
  * расширена информация о системе (включая данные об ОС)
* Улучшена работа системы обновления модулей и совместимости компонентов.
* Обновлены системные зависимости и пакеты для повышения стабильности.
