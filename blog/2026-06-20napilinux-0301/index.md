## Обновление NapiLinux 0.3.0.1

>**[Все версии...](https://download.napilinux.ru/napilinux/)**

Вышел релиз napi-linux 0.3.0.1
>Скачать: https://download.napilinux.ru/napilinux/0.3.0.1

## Что изменилось

Основные изменения:

- Добавлена поддержка управления SNMP через веб-интерфейс и API.
- Улучшена производительность работы встроенного веб-сервера за счёт оптимизации обработки запросов.
- Для устройств napi-c с eMMC включён высокоскоростной режим HS200, что значительно увеличивает скорость работы встроенного накопителя.
  * Чтение: до 125 MiB/s
  * Запись: до 108 MiB/s
- Добавлен новый Device Tree Overlay rk3308-spi2-w5500 для подключения Ethernet-контроллера W5500 по SPI.
- Обновлена конфигурация Device Tree для платформ RK3308: упрощены и модернизированы оверлеи.
- В веб-интерфейс добавлен
