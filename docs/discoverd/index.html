Поиск устройств в сети

1. Для чего нужна утилита​

discoverd — это утилита для обнаружения устройств на базе ОС napilinux в локальной сети.

Она помогает найти ваше устройство и узнать его идентификатор (id) и IP-адрес. Это полезно, например, если устройство получило адрес автоматически по DHCP, но вы не знаете, какой адрес ему назначен.

2. Скачать релиз​

Готовые релизы можно скачать здесь

Скачайте архив для вашей платформы, распакуйте его и перейдите в папку с бинарным файлом discoverd.

3. Поддерживаемые платформы​

Работа под Windows на данный момент не гарантирована.

Рекомендуется использовать macOS или Linux.

4. Запуск в режиме клиента​

Устройство с ОС napilinux и компьютер, с которого выполняется поиск, должны находиться в одной локальной сети.

Запустите команду:

./discoverd --mode client

Пример вывода при обнаружении устройства:

[2026-03-02T09:11:08Z] server discovered: id=napi-proudbuffalo ip=192.168.1.54

Если вы видите строку server discovered, значит устройство успешно найдено в сети.

5. Другие способы поиска​

Для поиска устройства также можно использовать сторонние утилиты:

  • Angry IP Scanner — сканер сети с графическим интерфейсом для Windows, macOS и Linux.
  • Nmap — утилита командной строки для обнаружения активных устройств и проверки доступных сетевых сервисов.

Эти утилиты показывают найденные устройства и их IP-адреса, но не всегда позволяют однозначно определить, какое из них работает на napilinux в отличие от discoverd.

Если на устройстве включен веб-интерфейс, доступный по HTTPS на TCP-порту 443, можно искать устройства с открытым портом 443. Например, с помощью Nmap:

nmap -sT -Pn -p 443 --open 192.168.1.0/24

Замените 192.168.1.0/24 на подсеть вашей локальной сети. Для найденного IP-адреса попробуйте открыть https://<IP-адрес> в браузере. Открытый порт 443 сам по себе не означает, что устройство работает на napilinux; если веб-интерфейс выключен или порт недоступен, такой поиск его не обнаружит.
